    asymcat.scorer functions¶

    Functions that compute a measure from raw series or a contingency table, and helpers that transform the dictionaries returned by CatScorer.

    Defines the various scorers for categorical co-occurrence analysis.

    scale_scorer ¶

    scale_scorer(scorer: dict[tuple[Any, Any], tuple[float, float]], method: str = 'minmax', nrange: tuple[float, float] = (0, 1)) -> dict[tuple[Any, Any], tuple[float, float]]

    Scale a scorer.

    The function returns a scaled version of a scorer considering all the asymmetric scorers (i.e., both x given y and y given x). Implemented scoring methods are "minmax" (by default on range [0, 1], which can be modified by the nrange parameter) and "mean".

    Parameters:

    Name Type Description Default
    scorer dict

    A scoring dictionary.

    		 required
    method str

    The scoring method to be used, either "minmax" or "mean" or "stdev" (default: "minmax").

    		 'minmax'
    nrange tuple

    A tuple with the scaling range, to be used when applicable (default: (0, 1)).

    		 (0, 1)

    Returns:

    Type Description
    dict

    A scaled version of the scorer.

    conditional_entropy(x_symbols: list[Any], y_symbols: list[Any], estimator: str = 'plugin') -> float

    Computes the entropy of x given y.

    Parameters:

    Name Type Description Default
    x_symbols List[Any]

    A list of all observed x symbols.

    		 required
    y_symbols List[Any]

    A list of all observed y symbols.

    		 required

    Entropy estimator: "plugin" (default, the maximum-likelihood estimate), "chao_shen" or "nsb". The bias-corrected estimators compute H(X | Y) = H(X, Y) - H(Y) from separately corrected entropies, taking the observed symbols as the alphabet.

    compute_mutual_information ¶

    compute_mutual_information(x_symbols: list[Any], y_symbols: list[Any], estimator: str = 'plugin') -> float

    Compute the mutual information between X and Y.

    MI(X;Y) = Σ_x Σ_y p(x,y) * log(p(x,y) / (p(x) * p(y)))

    Parameters:

    Name Type Description Default
    x_symbols List[Any]

    A list of all observed x symbols.

    		 required
    y_symbols List[Any]

    A list of all observed y symbols.

    		 required
    estimator str

    Entropy estimator: "plugin" (default), "chao_shen" or "nsb". The bias-corrected estimators compute MI = H(X) + H(Y) - H(X, Y) from separately corrected entropies, which can be slightly negative on small samples.

    		 'plugin'

    Returns:

    Type Description
    float

    The mutual information between X and Y.

    Compute the normalized mutual information between X and Y.

    A list of all observed y symbols.

    		 required
    estimator str

    Entropy estimator: "plugin" (default), "chao_shen" or "nsb" (see compute_mutual_information). Bias-corrected estimates are not confined to [0, 1].

    		 'plugin'

    Returns:

    Type Description
    float

    The normalized mutual information between X and Y, in range [0, 1] for the plug-in estimator.

    compute_goodman_kruskal_lambda ¶

    compute_goodman_kruskal_lambda(x_symbols: list[Any], y_symbols: list[Any], direction: str = 'y_given_x') -> float

    Compute Goodman and Kruskal's Lambda for asymmetric association.

    λ(Y|X) = (Σ_x max(n_x,y) - max(n_y)) / (n - max(n_y))

    Parameters:

    Name Type Description Default
    x_symbols List[Any]

    A list of all observed x symbols.

    		 required
    y_symbols List[Any]

    A list of all observed y symbols.

    		 required
    direction str

    Either "y_given_x" or "x_given_y" to specify direction.

    		 'y_given_x'

    Returns:

    Type Description
    float

    The Goodman-Kruskal Lambda coefficient, in range [0, 1]. When the predicted variable takes a single value there are no errors to reduce, and the coefficient is 1.0 by convention, as for compute_theil_u.
