# How-to guides

Task-oriented guides, each answering one practical question. They assume you
have read the [Tutorial](../getting-started/tutorial.md).

- **[Prepare co-occurrence data](prepare-data.md):** from table columns,
  aligned sequences, n-grams, whole sequences, files and presence–absence
  matrices.
- **[Work with sparse data](sparse-data.md):** smoothing the probabilities and
  correcting the entropies.
- **[Test significance and uncertainty](significance.md):** parametric tests,
  permutation tests, bootstrap confidence intervals and testing many pairs.
- **[Rank, scale and compare scores](compare-scores.md):** ranking pairs,
  finding asymmetric ones, rescaling and combining measures.
- **[Plot score matrices](plot.md):** heatmaps of both directions.
- **[Summarise whole variables](whole-variables.md):** one number for two whole
  variables, rather than one per pair.
